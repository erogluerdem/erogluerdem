```
[ Web / Mobile Clients ]  ─── (HTTPS / WSS) ───┐
                                              ▼
[ Edge CDN & WAF (Vercel / Cloudflare) ] 
       │
       ▼
[ Next.js 15+ Enterprise Core ] 
  ├── App Router (RSC & Server Actions)
  ├── RBAC & WebAuthn Security Layer
  └── Multi-Locale i18n Engine (13 Languages)
       │
       ├───► [ Primary DB: PostgreSQL + Prisma ORM ] (ACID Transactions)
       ├───► [ Cache & Distributed Lock: Redis ] (Rate Limiting)
       │
       ▼
[ Integration & Queue Worker Hub ]
  ├── ⚡ Pazaryeri Hub (Trendyol / Hepsiburada / N11)
  ├── 💬 WhatsApp Business Cloud API (Automated Orders & Alerts)
  └── 🔄 Bidirectional ERP Sync Daemon (Logo Tiger/Go, Mikro, Netsis)
```
